뽑기 웹 소개

뽑기 웹은 이름 뽑기, 룰렛, 번호 추첨, 벌칙 정하기 기능을 제공하는 무료 랜덤 도구 사이트입니다. 학교, 회사, 친구 모임, 가족 모임에서 발표 순서나 간단한 게임 결과를 정할 때 사용할 수 있습니다.

별도의 회원가입 없이 바로 사용할 수 있으며, 스마트폰, 태블릿, PC 화면에 맞게 자동으로 조절되는 반응형 웹으로 제작되었습니다.

사용 방법

원하는 기능 버튼을 누른 뒤 이름, 항목, 숫자 범위, 벌칙 내용을 입력하고 실행 버튼을 누르면 결과가 무작위로 표시됩니다.

공정성 안내

이 사이트의 결과는 브라우저의 무작위 숫자 생성 기능을 사용해 정해집니다. 특정 이름이나 항목을 일부러 유리하게 만들지 않습니다.

추천 콘텐츠

향후 광고 또는 추천 콘텐츠가 표시될 수 있는 영역입니다.

개인정보처리방침

사용자가 입력한 이름, 항목, 번호, 벌칙 내용은 서버에 저장하지 않습니다. 입력한 정보는 현재 브라우저 화면에서 기능 실행을 위해서만 사용됩니다.

본 사이트는 향후 Google AdSense 같은 광고 서비스를 사용할 수 있으며, 광고 서비스는 쿠키를 사용할 수 있습니다.
